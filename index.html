01 / The project

A small-scale system for more deliberate water use.

An ESP32 brings soil-moisture monitoring and environmental sensing into a controlled irrigation setup. Rainwater reuse and a three-level growing structure extend the idea from sensor to farm. A separate Blynk-connected app provides device monitoring and controls.

How the recommendation changes
  • Rapidly falling soil moisture can increase irrigation requirement.
  • Higher temperature can increase the drying tendency.
  • Higher humidity can reduce the immediate requirement.
  • Rising moisture can reduce the immediate requirement.
  • A recent irrigation event can delay another watering cycle.
  • Season and crop profile can modify target moisture behaviour.

This is an adaptive/intelligent decision model, not a claim that the physical prototype runs a large machine-learning model.

Season modes are software irrigation profiles, not weather forecasts. Crop profiles do not create independent sensing or watering for individual layers.

Why not a single threshold?

A fixed threshold treats every situation the same. An adaptive approach can consider environmental conditions, recent moisture behaviour and previous irrigation before recommending the next watering action.

SCENARIO A / ILLUSTRATIVELOW MOISTURE + HIGH TEMPERATURE + FALLING TRENDHIGHER IRRIGATION REQUIREMENT
SCENARIO B / ILLUSTRATIVEMOISTURE RISING + RECENT IRRIGATION + HIGH HUMIDITYLOWER IMMEDIATE REQUIREMENT

Project Overview

About The Project

"Our project is an IoT-Based Smart Irrigation and Multi-Layer Farming System designed to reduce water wastage and improve the efficiency of farming. The system uses an ESP32 microcontroller along with soil moisture, temperature and humidity sensors to monitor farming conditions. Rainwater can be collected and reused for irrigation, while the smart irrigation system can control water supply according to soil moisture requirements. The multi-layer farming structure helps make better use of available space."

Purpose

Why We Built This

"We wanted to combine electronics, programming, IoT and sustainable farming into one practical system. Instead of simply monitoring the farm, our project focuses on using sensor data to make irrigation more efficient and reduce unnecessary water usage."
